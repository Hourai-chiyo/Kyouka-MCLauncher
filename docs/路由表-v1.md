# MC 启动器下载路由表 v1

- 生成时间：2026-10-20
- 适用范围：自研启动器的下载路由层（元数据 / 本体 / 加载器 / Java / Mod）
- 设计前提：**不内置任何第三方镜像，尤其是 BMCLAPI 与 MCIM**
- 所有「实测」数据均来自本机（中国大陆网络）2026-10-20 的直接下载测试；标「未验证」的项不要当结论用

---

## 0. 为什么砍掉 BMCLAPI

| 维度 | 结论 |
|---|---|
| 功能 | 它是唯一镜像 `client.jar` / `assets` 的常见第三方源（`/version/{v}/client`、`/assets/...`） |
| 合规 | Mojang EULA 要求「所有游戏下载与更新须来自**我们授权的源**」。BMCLAPI 不是授权源；Modrinth / CurseForge 都刻意不镜像游戏本体，只镜像加载器 maven |
| 速度 | 实测 BMCLAPI client 4.6 MB/s，而 **Mojang 官方实测 6.28 MB/s**——砍它不掉速 |
| 稳定性 | 其 manifest 会 302 跳到 `*.sakura.sld.tw` 节点，该节点曾整段不可达 |
| 结论 | **砍掉**。代价是一个单点（官方域），用「内容寻址本地缓存」对冲，而不是用另一个镜像对冲 |

## 1. 元数据层：两条完整独立链路

两条链路各自自洽，**整条切换**，不要交叉拼接。

### 链路 A · Mojang 原生（**默认首选**）

```
① manifest   GET https://launchermeta.mojang.com/mc/game/version_manifest_v2.json
              实测 200，277,821 B，1.11s
              （备用域名 piston-meta.mojang.com 同路径，实测 200，2.20s）
② version    GET {manifest 中该版本的 url}  → piston-meta.mojang.com/v1/packages/{hash}/{ver}.json
```

**为什么默认选它**：它是 EULA 意义上的「authorized source」；实测 6.28 MB/s 并不慢；链路最短（不做任何 URL 改写）。

### 链路 B · Modrinth（**仅作兜底**）

```
① manifest   GET https://launcher-meta.modrinth.com/minecraft/v0/manifest.json
              实测 200，230,947 B；结构 {latest:{release,snapshot}, versions:[...]}，共 919 个版本
② version    GET https://launcher-meta.modrinth.com/minecraft/v0/versions/{ver}.json
              实测 200，47,332 B（1.21.1）
```

注意两点：
1. 该 version json 内部 **`client.jar` / `server.jar` / `assetIndex` 仍指向 Mojang**，只有第三方加载器库被改写到 `launcher-meta.modrinth.com/maven/`。
2. **`launcher-meta.modrinth.com` 是 Modrinth App 的内部接口**（逆向所得，无公开文档、无 SLA、可能随时变更或限流）。所以它只能是兜底，不能当首选——**即使它是"大厂域名"**。

### 切换判据

| 条件 | 动作 |
|---|---|
| 链路 A（Mojang）manifest 3s 内无响应 / 非 200 / 内容校验失败 | 切链路 B（Modrinth） |
| 链路 B 同样失败 | 提示用户手动填写自定义 manifest URL |

---

### 元数据兜底：Minecraft Wiki（两条 manifest 都失败时才用）

Wiki **不是下载源**（不托管任何文件），但它是一个独立的版本索引，且开放 MediaWiki API：

```
GET https://minecraft.wiki/api.php?action=parse&page=Java_Edition_{ver}
      &prop=wikitext&format=json&formatversion=2
```

返回约 2 KB 的 wikitext（比 278 KB 的 HTML 干净得多），内含 Infobox 模板参数：

```
|date=August 8, 2024
|jsonhash=94f420093e771cd1e72614184736b044c747a8df
```

拿到 `jsonhash` 后可直接拼出**不经过 manifest 的版本 JSON 直链**：

```
https://piston-meta.mojang.com/v1/packages/{jsonhash}/{ver}.json
```

实测（2026-10-20，本机）：

| 版本 | 发布日期 | jsonhash 直链结果 |
|---|---|---|
| 1.4.7 | December 28, 2012 | ✅ 200，8,482 B |
| 1.12.2 | September 18, 2017 | ✅ 200，19,110 B |
| 1.21.1 | August 8, 2024 | ✅ 200，38,408 B |
| 26.3（当时最新） | September 15, 2026 | ✅ 200，43.9 KB |

**结论：只做兜底，不做主源。** 触发条件严格限定为「Mojang manifest 与 Modrinth manifest 全部失败」。
最新版本实测同样能取到 `jsonhash`（`96c00d95...`），比最初判断的更完整；但仍需容错——
1.4.7 这类老页面的 `date` 字段会夹带 wikitext 标记（`'''Pre-release''':`、`<br>`），解析前必须清洗。

附加可用页面：

| 页面 | 用途 |
|---|---|
| `Versions_missing_from_the_launcher` | 官方启动器清单里**缺失**的版本——想做"全版本支持"时的入口 |
| `Java_Edition_version_history` | 完整版本沿革 |
| 任意版本页 Infobox | 发布日期 / protocol version / data version / pack format / 最低 Java 要求 |

限制：
1. 社区编辑，模板参数名会变（我用 `\|date=` 抓 1.4.7 时就混进了引用文本），正则必须容错；
2. 有 Cloudflare 保护，注意请求频次；
3. **只提供索引与元数据，不提供文件与 sha1** —— 文件仍须从 Mojang 取。

## 2. 文件层（本体的唯一来源：Mojang，全部 hash 寻址）

```
client.jar    GET https://piston-data.mojang.com/v1/objects/{sha1}/client.jar
server.jar    GET https://piston-data.mojang.com/v1/objects/{sha1}/server.jar
libraries     GET https://libraries.minecraft.net/{group/path/artifact-ver.jar}
LWJGL natives GET https://build.lwjgl.org/release/{ver}/bin/{module}/{module}-natives-{os}.jar
第三方库      GET https://launcher-meta.modrinth.com/maven/{group/path/artifact-ver.jar}
asset index   GET https://piston-meta.mojang.com/v1/packages/{hash}/{id}.json
asset objects GET https://resources.download.minecraft.net/{sha1[0:2]}/{sha1}
```

实测（2026-10-20）：

| 文件 | 大小 | 耗时 | 速度 |
|---|---|---|---|
| client.jar（1.21.1） | 26,836,906 B | 4.27s | **≈6.28 MB/s** |
| server.jar（1.21.1） | 51,627,615 B | 7.49s | **≈6.89 MB/s** |
| libraries 样例（guava 2.9MB） | 2,890 KB | 2.12s | 1.36 MB/s |
| asset object 样例 | 8,565 B | 0.73s | — |

**关键性质：以上全部是内容寻址（URL / 文件名里带 sha1），因此天然可以做本地对象缓存与完整性校验。**

## 6. 规则表（伪代码，按文件类型路由）

```
route(url) =
  classify(url) → type
  candidates = TABLE[type]                 # 见下，按优先级
  for c in candidates:
     if cacheHit(c.hash): return cache(c)  # 内容寻址先查本地
     resp = fetch(c.url, firstByteTimeout=3s, stallTimeout=20s, minProgress=10%)
     if resp.ok and sha1(resp.body) == c.hash:
        cachePut(resp.body); return resp
     else:
        log(c, resp.reason); continue
  raise AllSourcesFailed(type, tried=candidates)

TABLE = {
  "manifest":    [ "https://launchermeta.mojang.com/mc/game/version_manifest_v2.json",
                   "https://piston-meta.mojang.com/mc/game/version_manifest_v2.json",
                   "https://launcher-meta.modrinth.com/minecraft/v0/manifest.json" ],

  "version_json":[ "{linkA}/v1/packages/{hash}/{ver}.json",
                   "{linkB}/minecraft/v0/versions/{ver}.json" ],

  "client_jar":  [ "https://piston-data.mojang.com/v1/objects/{sha1}/client.jar" ],
  "server_jar":  [ "https://piston-data.mojang.com/v1/objects/{sha1}/server.jar" ],
  "library":     [ "https://libraries.minecraft.net/{path}",
                   "https://launcher-meta.modrinth.com/maven/{path}",
                   "https://build.lwjgl.org/release/{v}/bin/{m}/{m}-natives-{os}.jar" ],
  "asset_index": [ "https://piston-meta.mojang.com/v1/packages/{hash}/{id}.json" ],
  "asset_obj":   [ "https://resources.download.minecraft.net/{h2}/{hash}" ],

  "neoforge":    [ "https://neoforged.forgecdn.net/releases/{path}",
                   "https://launcher-meta.modrinth.com/maven/{path}" ],
  "forge":       [ "https://maven.minecraftforge.net/{path}" ],
  "fabric_meta": [ "https://meta.fabricmc.net/v2/versions/loader" ],
  "fabric_lib":  [ "https://maven.fabricmc.net/{path}",
                   "https://launcher-meta.modrinth.com/maven/{path}" ],

  "java":        [ "https://api.adoptium.net/v3/...",
                   "https://mirrors.tuna.tsinghua.edu.cn/Adoptium/..." ],

  "modrinth":    [ "https://api.modrinth.com/v2/...", "https://cdn.modrinth.com/..." ],
  "curseforge":  [ "https://api.curseforge.com/v1/...", "https://edge.forgecdn.net/..." ],
}
```

**域名级快捷改写（最小可用版）**

```
maven.neoforged.net/releases/{X}   →  neoforged.forgecdn.net/releases/{X}
maven.neoforged.net/releases/{X}   →  launcher-meta.modrinth.com/maven/{X}   （备选，缺 installer）
```

## 7. 健康检查判据

| 判据 | 阈值 | 说明 |
|---|---|---|
| 首字节超时 | **3 s** | 超时即切候选 |
| 断流超时 | **20 s** 内进度 < 10% | 判失败；不要用「总耗时」做阈值，大文件会被误杀 |
| 内容校验 | **sha1 必须匹配** | 不匹配直接丢弃并切源，不重试同一 URL |
| 重试策略 | 同源 1 次，换源 1 次，全失败报错 | 避免对单一源造成请求风暴 |
| 302 处理 | 跟随，但记录 `Location` | BMCLAPI 曾 302 到坏节点；若自定义源出现同类情况，日志里要能看出来 |

---

### 实测波动 → 优先级必须自适应，不能写死

同一天两次测量（本机 17:30 与 17:50），同一批源出现**排名翻转**：

| 源 | 第一次 | 第二次 |
|---|---|---|
| ForgeCDN（NeoForge 官方） | 2637~3527 KB/s | 1584 KB/s |
| Modrinth maven | 1716~2153 KB/s | **2285 KB/s** |
| Forge maven | 3069~3718 KB/s | 3267 KB/s |
| Mojang manifest | 320 KB/s | 219 KB/s |

**结论：候选顺序不能写死。**

推荐做法：
1. 每个类型维护一组**允许的**候选源（合规前提：只放官方 + 明确许可的镜像）；
2. 实际使用时**并发探测首字节**，按实测耗时排序，从最快的开始；
3. 主源失败或断流才降级，并记录本次实测值；
4. 定期体检（`mcroute.py sources`）刷新排序缓存。

固定“官方永远第一”会在慢源上白等几十秒；固定“镜像永远第一”则违背合规优先级。**候选集合由合规决定，内部顺序由实测决定。**

## 8. CAS 本地缓存（对冲单点，替代镜像）

```
<appdata>/objects/{sha1[0:2]}/{sha1}
<appdata>/index/{type}/{id}.json      # 记录 type → (sha1, size, source)
```

规则：
1. 所有下载完成即按 sha1 落盘；命中缓存直接返回，不发网络请求。
2. 缓存目录可整体复制 / 换机迁移 / 备份——**这是「源全挂也能重装」的唯一保障**。
3. 定期 `sha1` 全量校验，损坏对象删除重下。
4. 提供「导出离线包」：把某版本闭包（version json + client + libraries + assets + loader）打成目录 + 清单。

**这是本方案里替代 BMCLAPI 的核心机制：用本地冗余对冲远端单点，而不是引入新的第三方。**

## 10. 合规约束（写进代码注释与 README）

1. **不分发任何 Mojang 文件**：安装包内不得含 `client.jar` / `libraries` / `assets`，只能运行时下载。
2. **优先且默认使用 Mojang 官方源**；第三方镜像（若有）必须是**用户手动填写**，默认关闭，并在 UI 注明「非官方源」。
3. **不内置第三方镜像**（BMCLAPI / MCIM 均不内置）。
4. README 与「关于」页必须显著声明：
   ```
   NOT AN OFFICIAL MINECRAFT PRODUCT.
   NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.
   ```
5. **名称不得以 Minecraft 作为主名称**；只能用次要描述（例：`XXX 启动器：一个 Minecraft 启动器`）。
6. 不提供绕过正版认证的手段；登录走 Microsoft OAuth。
